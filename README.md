# expandable-toolbar · 可扩展桌面小工具条

一个用 **AutoHotkey v2** 写的、常驻置顶的桌面小工具条。跟终端无关（Tabby / Windows Terminal / PowerShell / cmd 里都能用），不需要管理员权限。工具条平时缩成一条横排图标停在屏幕角落，点图标展开对应的小面板，用完自动收回。

目前内置三个小工具，架构可扩展——加新工具只要往脚本里的 `gTools` 列表加一项即可。

## 三个内置工具

### 截图缩略图面板
盯住一个截图文件夹（默认 `C:\MyDownload\claude_picture`），按修改时间倒序显示缩略图（最新在左上）。点某张缩略图，就把它的**绝对路径**（后面带个空格）打字进当前活动窗口——用来快速把截图喂给终端里的 AI 工具，省去开资源管理器找文件。

- 整格可点（点图片四周留白也能插入）
- 鼠标移到面板上滚滚轮翻看更多
- 面板上「换目录」可改文件夹

### 命令 / 文字片段
预存一批常用命令或文字，点一下插入到当前窗口。

- **每条可设别名**：面板上显示别名（加粗）+ 命令首行预览（灰字）
- **支持多行命令**
- **两种插入方式**：
  - 「文本」：直接把原文插进去（适合 prompt、单行命令、路径）
  - 「脚本」：把命令存成一个 `.ps1`，插入 `& '路径.ps1'`，回车即执行——适合多行命令（在 PowerShell 里 `cd` 等也能生效）
- **拖动排序**：按住卡片上下拖，松手落到新位置；也可点卡片右侧很淡的 ▲▼ 上下移一位
- **最多显示 7 行**，超过出滚动条、滚轮翻

### 时间戳转时区
填入秒级 Unix 时间戳（13 位自动当毫秒），实时显示各时区时间：

- 中国 (UTC+8) / UTC / PST (UTC-8) / PDT (UTC-7)
- 「现在」按钮一键填当前时间戳
- 点某行时间可复制到剪贴板

## 工具条本身的特性

- **常驻置顶**：定期把自己顶回置顶层最上面，不会被别的置顶窗口盖住
- **点图标切换**：点某个图标展开它的面板（贴在工具条正下方，下方不够就翻到上方）；再点当前图标收起；点别的图标直接切换
- **可拖动**：按住工具条拖到任意位置，展开的面板会跟着走；支持双屏（含高 DPI 缩放）
- **收起后缩成工具球**：收起状态停留约 1.5 秒，工具条会自动缩成一个半透明小圆球（中心一个扳手图标 + 一圈不透明对比环，白底也看得见轮廓）；半透明避免长期挡住下方内容，点球展开回工具条、球也可拖动
- 平时不抢焦点，只有你主动点图片 / 片段时才激活下层窗口做插入
- `Ctrl+Alt+I`：面板 ↔ 工具条 来回切
- 托盘菜单：打开文件夹 / 重新扫描 / 命令片段 / 开机自启开关 / 退出

## 依赖与运行

- **AutoHotkey v2**（本项目在 AHK v2.0.x 上开发）
- 运行方式二选一：
  1. 双击 `启动.cmd`（它用通配符找同目录的 `.ahk` 启动，避免中文路径在 OEM 代码页 437 下变乱码）
  2. 直接用 AutoHotkey v2 打开 `expandable-toolbar.ahk`
- ⚠️ `启动.cmd` 里写死了本机的 AHK 路径 `C:\no_install\AutoHotkey\AutoHotkey64.exe`，换机器请改成你自己的 AHK v2 路径。
- 命令行参数：`/min` 开机自启时最小化启动；`/install`、`/uninstall` 装 / 卸开机自启。

## 配置

脚本顶部「配置」区可直接改，常用的几项：

| 配置项 | 作用 |
|--------|------|
| `Folder` | 截图文件夹路径 |
| `SnipMaxRows` | 命令片段面板最多显示几行（默认 7，超过滚动） |
| `KeepOnTopMs` | 多久重新置顶一次（毫秒，防被盖住；0 关闭） |
| `IconFont` | 图标字体，默认 `Segoe Fluent Icons`（Win11 自带）；显示成方块就改成 `Segoe MDL2 Assets` |
| `EnableShiftWheelScroll` | 是否开启终端里 Shift+滚轮滚动 |

## 运行时会生成的文件（已在 .gitignore 排除，不入库）

- `截图面板.ini` —— 文件夹路径、工具条位置
- `截图面板-命令片段.txt` —— 你存的命令片段
- `命令脚本/cmd_*.ps1` —— 脚本模式片段对应的 .ps1
